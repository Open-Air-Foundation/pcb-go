# Instructions for AI agents

The instructions for this repository are in [`CLAUDE.md`](CLAUDE.md), in this folder. They are written for every AI agent, whatever its maker. Read that file in full before you read the design or answer a question about it.

What it holds:

- which git ref is which version of the board: tag `v2` is the produced one, and several branches with similar names are not;
- which document answers which question;
- the traps: parts that are not fitted, look-alike part numbers, a manufacturer's document that overrides another.

Where the rest is:

| What | Where |
|---|---|
| Overview of the repository | [`README.md`](README.md) |
| Hardware spec sheet of v2, the produced boards | [`SPEC-SHEET.md`](SPEC-SHEET.md) |
| Hardware spec sheet of v1 | [`SPEC-SHEET-v1.md`](SPEC-SHEET-v1.md) |
| Datasheets and other manufacturers' PDFs: the chips, the sensors, the display, the battery | [`documents/`](documents/README.md) |
| v3, and the documents that compare the versions (`VERSIONS.md`, `CHANGES-v3.md`) | branch `v3-reroute` |
